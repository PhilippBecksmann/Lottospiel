# Lottospiel

Ein Lotto-Spiel für die Konsole, geschrieben in Python (Projekt aus der Münchner Coding Akademy).

## Funktionen

- Bis zu 12 Tippfelder mit je 6 eindeutigen Zahlen (1-49)
- Pro Feld wahlweise manuelle Eingabe oder automatischer Tipp
- Superzahl (0-9)
- Zufällige Ziehung und Auswertung mit Gewinnstufen (3 bis 6 Richtige)
- Validierung der Eingaben (keine Buchstaben, Wertebereich, keine doppelten Zahlen)

## Starten

```
python lottospiel.py
```

Benötigt Python 3, keine zusätzlichen Pakete.

## Gelernte Konzepte

Funktionen, Schleifen, Listen (auch geschachtelt), Fehlerbehandlung mit `try/except`, f-Strings, das Modul `random`.
